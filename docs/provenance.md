# Source provenance

This repository is a clean-history curated export of the Web Fetch module
formerly maintained in the private Zalava development estate. It contains no
private Git history, credentials, generated output, or consumer dependency on
private package registries.

The module is rebuilt against the released public `org.zalava` API and
contract-kit artifacts. Its release tag, JAR checksum, and catalog entry are
recorded only after the built-artifact contract suite passes.
